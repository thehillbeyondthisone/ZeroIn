    ZeroIn Command v5.2 - Help
    Keyboard Shortcuts
    H - Show/hide this help
    R - Reset view to player position
    C - Toggle Clan filter
    O - Toggle Omni filter
    N - Toggle Neutral filter
    A - Toggle AFK filter
    Calibration Modes
    Drag Radar: Calibrate the main map by dragging your player marker to align with the actual map. Saves zone offset coordinates.
    Drag Minimap: Calibrate local map overlays (like ICC map) by dragging and resizing the overlay to match the main map.
    Map Controls
    Mouse Wheel: Zoom in/out
    Left Click + Drag: Pan the map
    Snap To Player: Centers the local map overlay on your position
    Flip X/Y: Mirror the local map overlay to match orientation
    Player Markers
    ● Red: Clan players
    ● Blue: Omni players
    ● Gray: Neutral players
    ◐ Orange: AFK players (striped pattern)
    ● Green (glowing): Your position
    Configuration
    All calibration data is saved to browser localStorage
    Use "Save JSON" to export configuration
    Use "Reset" to clear all calibration data
